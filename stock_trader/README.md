# 키움증권 단타 자동매매 (변동성 돌파 전략)

> ⚠️ 투자 손실 책임은 본인에게 있습니다. 반드시 **백테스트 → dry → 모의투자 → 소액 실전** 순서로 검증하세요.
> 이 프로그램은 수익을 보장하지 않으며, 과거 성과가 미래 수익을 뜻하지 않습니다.

## 전략: 변동성 돌파
- **매수**: 현재가 ≥ 목표가(`오늘 시가 + (전일 고가 − 전일 저가) × k`)이면 시장가 매수 (종목당 하루 1회, 09:05~14:30)
- **매도**: 15:15에 전량 시장가 매도 (당일 청산, 오버나잇 위험 없음) / 손절가(기본 −2%) 도달 시 즉시 매도
- **필터**: 전일 종가가 5일 이동평균 위일 때만 매매 (하락 추세 종목 회피)

## 안전장치
| 장치 | 설명 |
|---|---|
| 모드 3단계 | `dry`(주문 없이 신호만 기록) → `mock`(키움 모의투자) → `real`(실전, 시작 시 `REAL` 입력 필요) |
| 하루 손실 한도 | 넘으면 전량 매도 후 그날 매수 중지 (`daily_loss_limit`) |
| 최대 보유 종목 / 종목당 금액 | `max_positions`, `budget_per_stock` |
| 하루 최대 주문 횟수 | 오류로 주문이 반복되는 사고 방지 (`max_orders_per_day`) |
| 긴급 정지 | `3_긴급정지.bat` 실행 (또는 폴더에 `STOP` 파일 생성) → 전량 매도 후 종료. Ctrl+C도 전량 매도 후 종료 |
| 재시작 보호 | 프로그램을 다시 켜도 오늘 이미 산 종목은 다시 사지 않음 |

## 1단계: 준비
1. **키움증권 계좌** + **모의투자 신청** (키움 홈페이지/영웅문 → 모의투자)
2. **REST API 신청**: https://openapi.kiwoom.com 에서 API 사용 신청 → **앱키(appkey) / 시크릿키(secretkey)** 발급
   (모의투자용 키와 실전용 키는 따로 발급됩니다. 접속 IP 등록이 필요할 수 있습니다.)
3. Python 설치 (https://www.python.org, 설치 시 "Add python.exe to PATH" 체크)

## 2단계: 백테스트 (API 키 없이 가능)
`1_백테스트.bat` 더블클릭 → config의 감시 종목으로 k 값 0.3~0.8 결과를 비교합니다.
```
python backtest.py --codes 005930 000660 --start 2023-01-01 --sweep
python backtest.py --k 0.5 --ma 5 --stop 2      # 거래 내역이 backtest_종목코드.csv 로 저장
```
**승률, 누적수익, 최대낙폭**을 보고 수익이 나는 종목과 k를 고르세요. 수익이 안 나는 종목은 감시 목록에서 빼세요.
(일봉으로 계산한 근사치라 실제 장중 움직임과 다를 수 있습니다.)

## 3단계: dry → 모의투자 → 실전
1. `2_자동매매_시작.bat` 실행 → 처음엔 `config.ini`가 열립니다. **모의투자 키**를 넣고 `mode = dry`로 저장
2. 장 시작 전(08:50쯤) 실행해 두면 09:00부터 자동으로 동작하고 15:15에 청산 후 종료됩니다
3. `logs/` 폴더에서 기록 확인: `trader_날짜.log`(전체 기록), `trades_날짜.csv`(매매 내역)
4. dry로 며칠 문제가 없으면 `mode = mock`으로 **2~4주 모의투자**
5. 모의투자에서도 괜찮으면 **실전 키**로 바꾸고 `mode = real`, **소액**(`budget_per_stock`을 작게)부터 시작

## 설정 (`config.ini`)
`config.example.ini`에 항목별 설명이 있습니다. 주요 항목: `watchlist`(감시 종목), `k`, `stop_loss_pct`,
`budget_per_stock`, `max_positions`, `daily_loss_limit`. 비용(`[cost]`)은 본인 수수료율과 **현재 증권거래세율**로 맞추세요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `kiwoom_api.py` | 키움 REST API 호출 (토큰, 시세, 일봉, 주문, 잔고). 키움 명세 변경 시 이 파일만 수정 |
| `strategy.py` | 목표가 계산, 이동평균 필터, 호가 단위 |
| `backtest.py` | 과거 데이터 백테스트 (FinanceDataReader 무료 데이터) |
| `trader.py` | 실시간 자동매매 + 안전장치 |

## 주의
- `config.ini`에는 API 키가 들어갑니다. **절대 공유하거나 저장소에 올리지 마세요** (`.gitignore`로 제외됨).
- 키움 API의 필드명·요청 형식은 키움 개발자 문서 기준으로 작성했지만, **실제 모의투자 서버에서 처음 실행할 때 로그를 꼭 확인**하세요.
  오류가 나면 로그 내용을 알려주시면 수정합니다.
- 실행 중에는 PC가 절전 모드로 들어가지 않게 설정하세요.
